# Inventario QR – Planta Piloto

Versión para GitHub Pages conectada a la misma base Supabase del inventario.

## Funciones
- Login/registro por email
- Dashboard
- Inventario con búsqueda y filtro por categoría
- Categorías: Tubos, Lanzas, Reactivos químicos, Instrumentación, Insumos básicos, Crisoles, Resistencias, Tapas de horno, Termocuplas, Sondas, O-rings y Otra
- Dimensiones opcionales: diámetro interno, diámetro externo, largo, espesor
- Hasta 3 fotos por producto
- Entradas, salidas y ajustes
- Borrado físico solo si el producto no tiene movimientos
- QR por producto
- Escáner QR
- Exportación Excel
- Diseño responsive

## Publicación
Este repositorio incluye un workflow de GitHub Actions para GitHub Pages.
En GitHub: Settings → Pages → Source → GitHub Actions.
